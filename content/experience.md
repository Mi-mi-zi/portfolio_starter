# Experience

## Talent Researcher Intern (AI Onboarding Assistant project), IRIS Software Group, August 2026

I built an onboarding assistant in Microsoft Copilot Studio for real internal use across the company. It serves three groups of people: hiring managers, people managers and new hires, who each need different information.

I reduced its response time from 158 seconds to 12 seconds by restructuring the metadata and separating the documents.

I designed a two-tier retrieval setup with prioritised sources and fallback logic. I also used Microsoft Entra ID and the Graph API so the assistant could personalise answers to the person asking.

I improved retrieval accuracy by uploading and labelling about 25 source documents individually.
